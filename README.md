# Examination_Portal

A web-based examination system built to conduct online exams with automated evaluation, real-time monitoring, and secure exam sessions.

### Tech Stack
- **Frontend:** React.js
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **Code Execution:** Judge0 API

### Key Features
- Online exam management
- Automated evaluation of objective questions
- Exam timer and automatic submission
- Candidate and examiner portals
- Activity monitoring and tab-switch tracking
- Secure authentication

### Getting Started
1. Clone the repository.
2. Set up the backend dependencies.
3. Configure the environment variables.
4. Start the FastAPI backend.
5. Install frontend dependencies and start the React application.
